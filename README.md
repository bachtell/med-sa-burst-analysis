# med-sa-burst-analysis

A modular MATLAB pipeline for analyzing Med-PC self-administration data with integrated burst detection and session-level behavioral summary statistics.

This repository was developed to process Med-PC C-array behavioral output files from rodent drug self-administration experiments. The workflow reconstructs behavioral event timestamps, computes self-administration metrics, detects burst-like intake behavior, and exports organized summary tables for visualization and statistical analysis.

---

# Overview

This pipeline is designed to support analyses of:

- Rodent self-administration behavior
- Escalation of intake across sessions
- Burst-like drug-taking patterns
- Sex differences in intake patterns
- Genetic strain differences in behavior
- Longitudinal behavioral trajectories

---

# Features

## Self-Administration Metrics
- Correct lever responding
- Incorrect lever responding
- Timeout responding
- Normalized timeout responding
- Lever discrimination
- Inter-infusion intervals
- Early-session intake measures
- Latency-to-infusion metrics
- Drug loading measures

## Burst Metrics
- Burst episode detection
- Burst duration
- Burst infusion counts
- Burst infusion ratio
- Average presses per burst
- Inter-burst intervals

## Data Processing
- Automated Med-PC parsing
- Timestamp reconstruction
- Session-level summary outputs
- Long-format and wide-format exports
- Excel workbook generation
- Longitudinal session organization

- compile_session_metrics
- create Excel file in wide format

---

# Input File Strucure
This pipeline expects a single Med-PC .txt files containing:
- Subject IDs (multiple subjects with unique IDs)
- Single session metadata per .txt file
- C-array events

Example filenames:
StrainRatLgA1.txt

---

# Burst Definition
A burst is defined as:
- ≥ minimum number of responses
- Occurring within a fixed inter-response interval

Default parameters:
- params.burstThreshold = 9000;
- params.minBurstResponses = 3;

These can be modified in config/analysis_parameters.m

---

# Output Files

## Long-format summary

Generated by:
run_analysis.m

File:
Burst_SA_Summary_01012001.txt

Contains:
- one row per subject per session
- all computed behavioral metrics

## Wide-format Excel workbook

Generated by:
compile_session_metrics.m

File:
Burst_SA_Summary.xlsx

Contains:
- one sheet per metric
- one animal per row
- sessions arranged longitudinally in columns
